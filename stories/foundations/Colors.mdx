# Colors

Semantic colours (`tokens/semantic/*.json`) alias the brand palette (`tokens/brands/<brand>.json`).
Components use only the semantic names. Each swatch shows the CSS custom property, the value resolved
for the brand and theme picked in the toolbar, and the alias it points at.
