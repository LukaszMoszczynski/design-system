# Typography

Font families, weights and brand sizes come from `tokens/brands/<brand>.json`. The type scale from
`tokens/breakpoint/*.json` is fluid: each size runs from its Mobile value at 375 px to its Desktop value
at 1200 px. Values below are resolved at the current width.
